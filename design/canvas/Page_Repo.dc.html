Источник
Из системы был только plakat-tokens.json (3a, v0.2.0). Страниц «Ядро», «Компоненты», «Текстуры» не было: геометрия компонентов выведена из токенов. Сверить с этими страницами до голденов.
Нажатие
Строка PR, пункта или проверки открывает GitHub (значок ↗).
Закрыть
Широкий: ✕ закрывает панель, строка на доске теряет выделение. Узкий: ← назад к доске.
Прокрутка
Панель прокручивается целиком под строкой с названием. Доска слева прокручивается отдельно.
Перенос
Заголовки PR и пунктов не обрезаются: переносятся на нужное число строк.
Нет в ките
Правая панель шириной 480 рядом с доской: не Dialog и не NavigationDrawer — свой контейнер с левым брусом 3.
Нет в ките
Бейджи статуса пункта: «Ждёт ответа» — ocher, «В работе» — slate, «Открыт» — контур hair. PR: «Проверки упали» — штриховка, «Готов к вливанию» — клин, «Проверки идут» — slate.
Нет в ките
Строка проверки: штриховка, имя проверки, «Ошибка», ↗.
Предложение
В tacku «Ещё 9» раскрывает остальные пункты по месту. В брифе этого нет: решить.
Не из токенов
Высота шапки 64 (широкий) и 56 (узкий) + брус 8. Бейдж 20 по высоте. Иконки нарисованы линией rule 3, butt/miter: набора иконок в токенах нет. Отступы 24 и 32 взяты кратными шагу сетки 8.
Трактовка
Приводка 1,1: у display/headline — красный оттиск под краской, у плашек — краска под красным. Текстура бумаги — своя feTurbulence с tile 256, opacity 0.45, multiply из токенов. Срез cut 46×14 не применён: неясно, к чему он.
Не из токенов
Код (gh auth token, имя переменной) набран Golos Text 600 на concrete: моноширинного текстового шрифта в ките нет.
