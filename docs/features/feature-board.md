# Доска портфеля

## 1. Обзор

Одна таблица отвечает на вопрос «куда смотреть первым»: строка на репозиторий с состоянием CI
основной ветки, открытыми PR, выполнением плана и числом пунктов, ждущих владельца. Сверху сводка:
выполнение плана по портфелю, число красных main, открытых PR и пунктов, ждущих владельца.

Экран — [screen-board](../screens/screen-board.md). На вебе данные приходят через
[endpoint-snapshot](../api/endpoint-snapshot.md); на десктопе API нет, сбор идёт в процессе
([feature-refresh](feature-refresh.md)).

## 2. Бизнес-правила

* План репозитория = `done + open + wip + question`; `dropped` в план не входит.
* Выполнение = `done / план`, округление вниз до целого процента; 100 % показывается только когда
  `open + wip + question = 0`.
* Выполнение портфеля = сумма `done` / сумма планов по репозиториям с формой `Items`.
* «Ждут владельца» = число пунктов со статусом `Question`.
* Порядок строк по умолчанию: `Red` main, затем есть PR `Failing`, затем есть `Question`, затем
  есть открытые PR, затем по времени последнего push (*принято при раскладке:* новее выше, и
  внутри каждой группы тоже — [исследование §3.1, п. 2](../research/research-architecture.md)).
* Фильтры: «Все», «Красные» (`Red` main или PR `Failing`), «С PR», «Ждут меня»; поиск по имени
  репозитория без учёта регистра.
* У репозитория с формой `Flat` или `None` вместо процента стоит пометка («план одним файлом»,
  «бэклога нет»); в сводку он не входит.

## 5. Сценарии

Все сценарии — *целевые*: задуманное поведение, сверяется с кодом до того, как документ станет
`active`. Данные — примерные данные §5a брифа (12 публичных репозиториев, снимок 12.11.2026 в
09:17), они же — фикстуры.

### Scenario: An ordinary day
* **Given:** снимок из примерных данных.
* **When:** доска открыта.
* **Then:** первой стоит `youndie/tacku` (красный main); сводка показывает 95 %, 1 красный, 12 PR,
  7 ждут.

### Scenario: The search finds nothing
* **Given:** тот же снимок.
* **When:** в поиске набрано `zzz`.
* **Then:** доска показывает состояние `NoMatches` с кнопкой сброса; сводка не меняется.

### Scenario: The plan is not quite done
* **Given:** репозиторий с `done = 179`, `open = 1`.
* **Then:** выполнение показывает 99 %, а не 100 %.

## 6. Вне объёма

* Действия записи (влить PR, перезапустить CI) — доска только читает.
* История и графики во времени.
* Подсчёт плана у репозиториев с плоским `BACKLOG.md`.

## 7. Причуды

* **«Красный» — два разных числа.** Сводка «1 красный» считает только `Red` main; фильтр «Красные»
  берёт `Red` main **или** PR `Failing`. На примерных данных фильтр показывает две строки
  (`youndie/tacku`, `youndie/kachok`) при сводке «1 красный» — это не ошибка.
* **Сводка не реагирует на фильтр и поиск.** Она описывает портфель, а не то, что сейчас видно в
  таблице.
