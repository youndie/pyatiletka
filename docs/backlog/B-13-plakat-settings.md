# B-13 — plakat: настройки

Настройки — только десктоп, только широкий размер ([screen-settings](../screens/screen-settings.md)).

- **Решение и причина.** Поля для ввода токена нет ни на холсте, ни в коде.

- AC: для каждого `Settings_*` измерен `viddikDesignParity`, остаток выше допуска разобран по областям с
  причиной (вид кита принят владельцем, [B-11](B-11-plakat-board.md)); голдены записаны.
- Якоря: `skin-plakat/src/commonMain/kotlin/io/github/youndie/pyatiletka/skin/plakat/`.

## Итог (12.11.2026)

Настройки на plakat-ui (`skin-plakat/…/PlakatSettings.kt`) во всех четырёх состояниях. Экран
подключён к окну десктопа: «Настройки» на доске ведут на экран через `Navigator`, ← возвращает;
`DesktopSettings` работает поверх `SettingsModel`. Голдены `Settings_*` записаны.

Паритет (`viddikDesignParity`, допуск 5 % / ±16 не менялся): в допуске 0 из 4. Вид кита принят
([B-11](B-11-plakat-board.md)), поэтому ниже — разбор остатка по областям.

| Артборд | Паритет | Остаток по областям |
|---|---|---|
| Content | 6,10 % | управление 4,81 %: у радиокнопки кита своё поле 48, текст правее на 24; сегменты и поле кита; нет числа репозиториев у владельца. Пояснения 1,17 % — разделы ниже холста по высоте |
| TokenMissing | 7,27 % | то же; плюс недоступные поле, кнопка и сегменты так, как их рисует кит (пунктир), а не приглушённо, как на холсте |
| TokenRejected | 6,75 % | то же; строка «Ошибка» |
| OwnerNotFound | 6,84 % | то же; ошибка поля — штриховка кита под полем, а не строка холста |

Решения по ходу:

- **Слова кита — по-русски.** У `PlakatTheme` есть `strings`, а `PlakatSkin` их не передавал, поэтому
  ошибка поля начиналась с «ERROR.». Теперь `RussianStrings` передаётся в теме скина и в фикстурах;
  голдены доски и карточки от этого не изменились.
- **Числа репозиториев у владельца нет**: его нет в `SettingsUiState`. Записано в screen-settings §4.5.
