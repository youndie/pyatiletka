# B-12 — plakat: карточка репозитория

Карточка — правая панель шириной 480 на широком и отдельный экран на узком ([screen-repo](../screens/screen-repo.md)).

- **Решение и причина.** После доски: панель стоит рядом с доской, и артборд широкого размера включает её.

- AC: для каждого `Repo_*` измерен `viddikDesignParity`, остаток выше допуска разобран по областям с
  причиной (вид кита принят владельцем, [B-11](B-11-plakat-board.md)); голдены записаны.
- Якоря: `skin-plakat/src/commonMain/kotlin/io/github/youndie/pyatiletka/skin/plakat/`.

## Итог (12.11.2026)

Карточка на plakat-ui (`skin-plakat/…/PlakatRepo.kt`). На широком экране она стоит панелью 480 рядом
с доской, а доска сужается до 800 (`PlakatBoard(card = …)`); на узком это отдельный экран. Порядок
разделов: упавшие проверки, план или плакат «План выполнен», PR, пункты. Карточка подключена к окну и
странице: строка доски открывает её, строки ведут на GitHub через `LocalUriHandler`. Голдены записаны
для всех 10 артбордов (`RepoFixtures.kt`).

Паритет (`viddikDesignParity`, допуск 5 % / ±16 не менялся): в допуске 0 из 10. Вид кита принят
([B-11](B-11-plakat-board.md)), поэтому ниже — разбор остатка по областям.
