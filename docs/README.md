# docs — Пятилетка

Доска портфеля владельца (CI основной ветки, открытые PR, выполнение бэклогов) и первый боевой
потребитель UI-китов plakat-ui и toon-ui. Документация слоёная; ссылки идут сверху вниз.

```
[ Исследование (почему архитектура такая) ]
                     │
[ Фича (бизнес + BDD) ] ──▶ [ Экран ]
                               │
                               ▼
                     [ API (контракт снимка) ]
                               │
                               ▼
                     [ Модуль (что владеет, как собирается) ]
```

| Слой | Каталог | Отвечает | Источник правды |
|---|---|---|---|
| Исследование | `research/` | *почему* так; что проверено, что гипотеза | артефакты, названные у каждого факта |
| Фича | `features/` | *что* делает система и *зачем*; сценарии BDD | этот репозиторий |
| Экран | `screens/` | что видит пользователь: состояния, действия, навигация | этот репозиторий + код экрана |
| API | `api/` | файл снимка: путь, уровень доступа, ошибки | модуль `core` |
| Модуль | `services/` | роль модуля, зависимости, выкладка, конфигурация | этот репозиторий |

**Бэклог** — [backlog.md](../backlog.md): индекс и решения; пункты — файл на пункт в
[`backlog/`](backlog/), ссылка вида `[B-12](backlog/B-12-plakat-repo-card.md)`.

**Статус.** Кода ещё нет. Документы слоёв — `status: draft`, все пути в них *целевые*, все сценарии —
*целевые*; документ становится `active`, когда код даёт ему якоря и сценарии сверены с кодом.

## Соглашения

- **`id`** во frontmatter уникален и равен имени файла.
- Межслойные ссылки — id во frontmatter и обычные markdown-ссылки в тексте.
- Один документ — одна сущность.
- Сценарии BDD пишутся по коду: статусы и строки ошибок сверяются до того, как сценарий записан.
- **Главный читатель — агент.** В каждом документе есть якоря кода; то, что живёт в коде (поля DTO,
  ключи конфигурации), не копируется — даётся путь.
- В публичных документах, фикстурах и эталонах — только публичные репозитории.
- Язык: проза по-русски; идентификаторы, пути, имена классов, заголовки `### Scenario:` — по-английски,
  как в коде.

## Шаблоны

`templates/` — копии шаблонов docs-bootstrap, чтобы формат ехал вместе с репозиторием.

## Проверки

Makefile запускает проверки docs-bootstrap той версии, которую пинует
`.github/workflows/check.yaml`; CI запускает те же цели:

```bash
pip install pyyaml
make check      # гейт и отчёты: то же, что в CI
make fix        # пересобрать индекс бэклога, дописать недостающие строки карты покрытия
```
